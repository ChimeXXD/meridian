# Decisions

These were decided in brainstorming on 26 Oct 2026. Claude CLI treats them as fixed. To change one, add a new entry that supersedes it rather than editing the old one.

| ID | Decision | Why |
| --- | --- | --- |
| D-01 | Repo and codename are `next-episode`. The App Store display name is **Airstamp** (a `DISPLAY_NAME` setting in `project.yml`). | next-episode.net already ships an app called "Next Episode" with 2.5K ratings, which risks rejection under guideline 4.1. A search found no app or brand named "Airstamp". Before submitting, check the domain and the USPTO/EUIPO trademark registers. |
| D-02 | The 3-day build targets the MVP plus the hero features, not the full PRD Phase 0–2. | Three days with an AI agent is enough for the data core, widgets and a Live Activity, but not for region data, imports and the Watch app as well. |
| D-03 | Minimum target is iOS 26.0. iOS 27 APIs sit behind `#available`. | Scheduled Live Activities (`request(...start:)`) are iOS 26+. iOS 26 was on 79% of iPhones by June 2026. |
| D-04 | The project is generated with XcodeGen (`project.yml`). | It lets Claude CLI add targets, entitlements and the App Group as YAML instead of editing `.pbxproj`. |
| D-05 | Widgets and Live Activities read a JSON `DropSnapshot` in the App Group container. SwiftData stays in the app. | It is faster and simpler than sharing a SwiftData store with an extension, and the widget needs only the next few drops. |
| D-06 | Data sources for the MVP are **TVmaze** (TV) and **AniList** (anime). There is no TMDB in the 3-day build. | Both are keyless, so there is no secret in a public repo. TVmaze is CC BY-SA. AniList is free under $150/month revenue. TMDB needs a key and a commercial licence before any paid tier. |
| D-07 | "Where to watch" in the MVP is the **network or web channel name** from TVmaze (HBO, Apple TV, Netflix), labelled "On". The region-aware TMDB/JustWatch provider comes after day 3. | It is free, correct for originals, and needs no key. Showmax, which the PRD named, shut down on 30 Apr 2026, so the Nigeria provider list has to be re-researched anyway. |
| D-08 | A time-resolution layer (`TimeResolver` + `PlatformRules`) gives every drop a source and a confidence level. | TVmaze's `airstamp` is a placeholder (12:00 UTC) whenever `airtime` is empty, which covers most streaming drops. Wrong times are the main trust risk. |
| D-09 | Confidence levels are `exact`, `estimated` and `dateOnly`. `dateOnly` drops show a date and no ticking timer. | This is honest: the app never ticks down to a time it made up. |
| D-10 | The Live Activity is opt-in per show. The default lead time is 2 hours before the drop, and activities are scheduled for the next 7 days whenever the app comes to the foreground. Same-night drops merge into one activity. The activity ends with `.after(drop + 1h)`. | `request` must be called in the foreground. Activities run at most 8 hours active plus 4 on the Lock Screen. Apple publishes no simultaneous cap, so keep the count low and catch errors. |
| D-11 | A **Debug → "Fake drop in N minutes"** menu ships in Debug builds. | Most of Chime's real shows have no upcoming episode (Euphoria ended; Silo returns July 2027), so a countdown can't be tested without fake data. It also produces the portfolio video. |
| D-12 | Background refresh uses `BGAppRefreshTask` (about every 6 hours), caches responses for 6 hours, diffs drop times and marks "Delayed" when a time moves later. | TVmaze caches responses for 60 minutes server-side and limits clients to 20 calls per 10 seconds; AniList allows 90 a minute. |
| D-13 | Use a typographic design with no poster art. One display face (SF Pro Rounded or SF Compact for numerals, with tabular figures) and SF Pro for text. Support the Liquid Glass accented rendering mode. | It avoids copyright problems, gives the portfolio its hero shot, and holds up in tinted and clear Home Screen modes. |
| D-14 | Code is MIT-licensed in a public GitHub repo. A data notice in the README covers TVmaze CC BY-SA and AniList terms. | It is a portfolio repo. The MIT licence covers the code only; the data licences still apply. |
| D-15 | Positioning against Up Next and Rexy, which already ship Live Activities: **exact and honest times outside the US, TV and anime in one app, open source.** | The PRD's "nobody ships a Live Activity" gap closed in July 2026. |
| D-16 | Join the paid Apple Developer Program ($99/yr) on Day 0 if you haven't already. | Free provisioning expires every 7 days, App Group support on free accounts is unconfirmed, and TestFlight needs a paid account. |

### Refinements from the 29 Oct 2026 review

These came from the research update in `RESEARCH.md` (29 Oct). Where an entry supersedes an older one, it says so.

| ID | Decision | Why |
| --- | --- | --- |
| D-17 | **Supersedes D-15.** Lead with **"release times you can trust, wherever you are."** The Live Activity is a must-have that everyone ships, not our selling point. | Up Next (free), Rexy and Kiroku already ship Live Activity countdowns. No competitor shows where a time came from. Reviews of Trakt, Sofa and Next Episode complain about times 1–2 hours off, "12am" placeholders, and US times shown abroad. |
| D-18 | Platform rules and **per-episode overrides** live in `rules/platform-rules.json` in the public repo. The app bundles a copy, fetches the latest copy from the repo's raw URL at most once a day, validates it against the schema, and falls back to the bundled copy on any failure. Overrides are checked before rules. | Rules have exceptions: Netflix event drops at 17:00 PT (Stranger Things 5), Prime moved the Fallout S2 premiere forward, and Disney+ uses 18:00 PT for Marvel but 00:00 PT for other shows. Fixing a time shouldn't need an App Review. GitHub hosts the file, so we still run no server. The privacy policy must say the app fetches this file. |
| D-19 | Anime data from AniList depends on AniList's permission (O-5). Until they answer, build the AniList client behind a `CatalogSource` protocol and keep to **30 requests a minute**. If they say no, anime comes from TVmaze only. | AniList's terms prohibit "competing, non-complementary… list or tracker services", and its API is in a degraded 30/min state. TVmaze lists many anime with a JST airtime. Phase 1 measures how many. |
| D-20 | **Supersedes D-07's label.** The provider label shows the origin network or channel *and its country* ("HBO · US", "Netflix") until region data exists. When we know there is no legal stream, say "No official stream in your country". | HBO left Showmax in January 2026, and Showmax closed on 30 April 2026. Disney+ and Hulu aren't available in Nigeria. "On HBO" would mislead a Lagos viewer. |
| D-21 | Design gets its own phase. References come from **references** (saved to the "Airstamp references" collection) and the design system and every screen live in **Figma**. Built screens are checked against exported Figma frames. | Chime asked for it. It also turns "looks right" into a check: screenshot vs frame. |
| D-22 | A **"Report a wrong time"** action opens a prefilled GitHub issue, with email as a fallback for people without a GitHub account. | It is a feedback loop for accuracy that needs no server and no analytics, and the issue list doubles as a public accuracy log. |
| D-23 | **Supersedes D-02's schedule.** The MVP scope is unchanged, plus D-18 and D-22. The plan runs to the App Store over about 7 calendar weeks, including a 14-day beta with a 100-drop accuracy audit (`PLAN.md`). | Three days covered the build but not design, validation, beta or review. Accuracy is the product, so it has to be measured before launch. |
| D-24 | **Refines D-10.** Call `request(... start:)`, not `startDate:`, which exists only on iOS 26.0. Keep **at most 3 pending activities** and handle `ActivityAuthorizationError`. | Apple's docs say scheduled activities count toward a simultaneous limit whose number isn't published. |
| D-25 | Detect placeholders **only** by `airtime == ""`. Never test the airstamp for 12:00 UTC. | TVmaze's placeholder is noon in the *channel's country* time zone. That is 12:00Z for Netflix but 16:00Z (or 17:00Z in winter) for Peacock and Hulu (verified on the live `/schedule/web`, 28–30 Oct 2026). |
| D-26 | v1 is free with no in-app purchases. Decide on a tip jar or Plus at about 1,000 monthly users. | Free competitors already ship countdowns. Benchmarks are about $10–15/yr or $25–30 lifetime. A paid tier with TMDB data needs a commercial licence. |
| D-27 | **Supersedes D-12's promise.** Refresh happens when the app becomes active; `BGAppRefreshTask` is a bonus. The UI never promises an interval ("checks again each time you open it"). | iOS doesn't guarantee background refresh timing, and it never runs after a force-quit. Promising "every 6 hours" would be a false claim in an app built on honesty (D-17). |
| D-28 | A `dateOnly` drop keeps its listed airdate as a `yyyy-MM-dd` string and is formatted from that. This is a documented exception to CLAUDE.md rule 1, which still applies to every timed drop. | Storing "start of the local day" as a UTC instant shows the previous day to anyone west of where it was stored. |
| D-29 | Drop Day (the whole-season treatment) moves to Phase 9. | It needs episode runtimes, which v1 doesn't model, and it isn't part of the core "when and where" question. |
| D-30 | **Note on D-16.** App Groups *are* available on free provisioning (Apple capabilities table, 29 Oct 2026). The paid program is still needed for TestFlight and the App Store. | Corrects the "unconfirmed" in D-16. |
| D-31 | **Supersedes D-21.** There is **no Figma**; the product is vibe-coded straight into SwiftUI. **references** is the reference library: references per surface are saved to the "Airstamp references" collection and noted in `docs/design/REFERENCES.md`. A written `docs/design/UI-BRIEF.md` (elements, copy from SPEC, states, test IDs) is what screens are checked against. Chime approves each screen from simulator screenshots, and approved screenshots become the `fidelity/refs/` baselines for regression checks. | Chime's call (29 Oct 2026). A design tool adds a handoff step that a solo, agent-built app doesn't need. The brief keeps the build checkable without mockups. |
| D-32 | **Supersedes D-23 and D-26, and the App Store parts of the plan.** Airstamp is a **portfolio project**. It is built with AI in **one week** (Thu 29 Oct – Thu 5 Nov 2026) and stops at a **private beta**. There is no App Store release and no pricing. The repo is **private** while we build and goes **public** (open source, MIT) on Day 7; this supersedes D-14's public-from-day-one. | Chime's goal (29 Oct 2026): ship it to GitHub and the portfolio site as proof of work. App Store work (listing, review, privacy label, age rating, trademark) adds no portfolio value. |
| D-33 | Scope for the week is the Must / Should / Cut table in `PLAN.md`. If a day overruns, cut from its Should column; never cut Day 7 (README, video, case study, open source). | One week only fits the core demo, and the portfolio material is the actual deliverable. |
| D-34 | While the repo is private, the app uses only the **bundled** rules file, and "Report a wrong time" uses **email**. On Day 7, when the repo goes public, the remote rules fetch (D-18) and GitHub-issue reporting (D-22) are switched on. | A private repo's raw files and issues can't be reached by the app or by testers. |
| D-35 | **Supersedes D-16. Zero spend.** No Apple Developer Program, no TestFlight, no paid services. The app is signed with Chime's free Apple ID (Personal Team in Xcode). The private beta is Chime's iPhone, plus any friend's iPhone installed by cable from Chime's Mac. Builds expire after 7 days and are reinstalled from Xcode. While the repo is private, CI runs only on pushes to `main` (and by hand), to stay inside GitHub's free private-repo minutes; macOS minutes count 10×. Once the repo is public, CI runs on every push and PR. reference searches stay within the Day 2 query list. | Chime: "I don't want to spend a dime." App Groups and local (non-push) Live Activities work on free provisioning (Apple capabilities table, 29 Oct 2026); push isn't needed (D-10). Free accounts without a payment method stop at the minute limit rather than being charged. |
