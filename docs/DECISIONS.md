# Decisions

These were decided in brainstorming on 26 Oct 2026. Claude CLI treats them as fixed. To change one, add a new entry that supersedes it rather than editing the old one.

| ID | Decision | Why |
| --- | --- | --- |
| D-01 | *(Superseded by D-54.)* Repo and codename are `next-episode`. The App Store display name is **Airstamp** (a `DISPLAY_NAME` setting in `project.yml`). | next-episode.net already ships an app called "Next Episode" with 2.5K ratings, which risks rejection under guideline 4.1. A search found no app or brand named "Airstamp". Before submitting, check the domain and the USPTO/EUIPO trademark registers. |
| D-02 | The 3-day build targets the MVP plus the hero features, not the full PRD Phase 0–2. | Three days with an AI agent is enough for the data core, widgets and a Live Activity, but not for region data, imports and the Watch app as well. |
| D-03 | Minimum target is iOS 26.0. iOS 27 APIs sit behind `#available`. | Scheduled Live Activities (`request(...start:)`) are iOS 26+. iOS 26 was on 79% of iPhones by June 2026. |
| D-04 | The project is generated with XcodeGen (`project.yml`). | It lets Claude CLI add targets, entitlements and the App Group as YAML instead of editing `.pbxproj`. |
| D-05 | Widgets and Live Activities read a JSON `DropSnapshot` in the App Group container. SwiftData stays in the app. | It is faster and simpler than sharing a SwiftData store with an extension, and the widget needs only the next few drops. |
| D-06 | Data sources for the MVP are **TVmaze** (TV) and **AniList** (anime). There is no TMDB in the 3-day build. | Both are keyless, so there is no secret in a public repo. TVmaze is CC BY-SA. AniList is free under $150/month revenue. TMDB needs a key and a commercial licence before any paid tier. |
| D-07 | "Where to watch" in the MVP is the **network or web channel name** from TVmaze (HBO, Apple TV, Netflix), labelled "On". The region-aware TMDB/JustWatch provider comes after day 3. | It is free, correct for originals, and needs no key. Showmax, which the PRD named, shut down on 30 Apr 2026, so the Nigeria provider list has to be re-researched anyway. |
| D-08 | A time-resolution layer (`TimeResolver` + `PlatformRules`) gives every drop a source and a confidence level. | TVmaze's `airstamp` is a placeholder (12:00 UTC) whenever `airtime` is empty, which covers most streaming drops. Wrong times are the main trust risk. |
| D-09 | Confidence levels are `exact`, `estimated` and `dateOnly`. `dateOnly` drops show a date and no ticking timer. | This is honest: the app never ticks down to a time it made up. |
| D-10 | The Live Activity is opt-in per show. The default lead time is 2 hours before the drop, and activities are scheduled for the next 7 days whenever the app comes to the foreground. Same-night drops merge into one activity. The activity ends with `.after(drop + 1h)`. | `request` must be called in the foreground. Activities run at most 8 hours active plus 4 on the Lock Screen. Apple publishes no simultaneous cap, so keep the count low and catch errors. |
| D-11 | A **Debug → "Fake drop in N minutes"** menu ships in Debug builds. | Most of Chime's real shows have no upcoming episode (Euphoria ended; Silo returns July 2027), so a countdown can't be tested without fake data. It also produces the portfolio video. |
| D-12 | Background refresh uses `BGAppRefreshTask` (about every 6 hours), caches responses for 6 hours, diffs drop times and marks "Delayed" when a time moves later. | TVmaze caches responses for 60 minutes server-side and limits clients to 20 calls per 10 seconds; AniList allows 90 a minute. |
| D-13 | Use a typographic design with no poster art. One display face (SF Pro Rounded or SF Compact for numerals, with tabular figures) and SF Pro for text. Support the Liquid Glass accented rendering mode. | It avoids copyright problems, gives the portfolio its hero shot, and holds up in tinted and clear Home Screen modes. |
| D-14 | Code is MIT-licensed in a public GitHub repo. A data notice in the README covers TVmaze CC BY-SA and AniList terms. | It is a portfolio repo. The MIT licence covers the code only; the data licences still apply. |
| D-15 | Positioning against Up Next and Rexy, which already ship Live Activities: **exact and honest times outside the US, TV and anime in one app, open source.** | The PRD's "nobody ships a Live Activity" gap closed in July 2026. |
| D-16 | Join the paid Apple Developer Program ($99/yr) on Day 0 if you haven't already. | Free provisioning expires every 7 days, App Group support on free accounts is unconfirmed, and TestFlight needs a paid account. |
