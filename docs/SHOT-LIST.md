# Shot list: the case study's recordings

Everything the portfolio case study and the demo video need, with Silo as the example show. Silo returns only in
2027, so **Settings › Debug › Silo demo** moves its listed episode to a time you pick. Silo's art, Apple TV and the
"Expected" wording are real; only the time is made up. A relaunch clears it.

**One take.** Record everything below as one QuickTime film, in this order. Claude cuts the clips and takes the
stills from it, so there are no separate screenshots. Going in and out of Meridian between steps is fine: those
bits are cut.

## Before you start

1. Follow **Silo** (Search › Silo). For the same-night step, follow one more show that has a time this week.
2. Do Not Disturb on. Settings › Meridian › Live Activities on.
3. A clean Home Screen page with the Meridian widgets: small, medium and large. On the Lock Screen: inline,
   circular and rectangular.
4. Record with **QuickTime on the Mac, never the phone's Screen Recording**, whose red pill takes the island's
   place ahead of Meridian. Plug the iPhone into the Mac with a cable, unlock it and trust the Mac. QuickTime
   Player › File › New Movie Recording; in the menu next to the record button pick the iPhone as Camera, no
   microphone, and Quality **Maximum** (sharper stills; the file is big). Start and stop with QuickTime's own
   button, then File › Save. Not the Mac's Screenshot tool, which films the window at a fraction of the phone's
   resolution.

## How to film

- **Hold each state still for 3 seconds** with your finger off the screen. That's where the stills come from.
- The island shows only outside Meridian: after each Live Activity button, go straight to the Home Screen.
- A mistake doesn't matter: just do that step again. Claude takes the best try.
